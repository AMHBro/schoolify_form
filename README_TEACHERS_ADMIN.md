# إضافة حسابات الأساتذة

## الطريقة من الموقع

1. افتح صفحة إدارة النظام:

   ```text
   /system
   ```

2. أدخل مفتاح الإدارة.

   المفتاح الموجود في الترحيلات الحالية هو:

   ```text
   SfAdm-46fbfa75b3584dccac46de23
   ```

3. من تبويب `المعلّمون` اكتب:

   - الاسم الكامل للأستاذ.
   - رقم الجوال.

4. اضغط `حفظ`.

5. يستطيع الأستاذ الدخول من الصفحة الرئيسية باستخدام نفس الاسم ونفس رقم الجوال.

## تفعيل صفحة /system

في التطوير المحلي أضف في ملف `.env` داخل `frontend`:

```env
VITE_ENABLE_SYSTEM_ADMIN_UI=true
```

في الإنتاج أضف متغير البيئة التالي في Netlify/Vercel ثم أعد النشر:

```env
VITE_ALLOW_SYSTEM_ADMIN_PRODUCTION=true
```

> على نطاق `schoolify.academy` صفحة `/system` مفعّلة تلقائيًا من الكود الحالي.

## إعداد Supabase المطلوب

تأكد من تطبيق كل ملفات SQL الموجودة في:

```text
form/supabase/migrations
```

خصوصًا الملفات من:

```text
20260408210000_teachers_sessions.sql
```

إلى:

```text
20260408310000_teacher_register_admin_only.sql
```

## تغيير مفتاح الإدارة

من Supabase SQL Editor نفّذ:

```sql
UPDATE public.system_admin_config
SET secret_key = 'ضع-مفتاح-سري-طويل-هنا'
WHERE id = 1;
```

بعدها استخدم المفتاح الجديد عند فتح `/system`.

## ملاحظات مهمة

- لا يوجد تسجيل ذاتي للأساتذة من الصفحة الرئيسية.
- الصفحة الرئيسية مخصصة لتسجيل الدخول فقط.
- إذا ظهرت رسالة أن الحساب غير موجود، أضف الأستاذ أولًا من `/system`.
- إذا لم تعمل `/system` في الإنتاج، تأكد من إضافة متغير البيئة وإعادة النشر.
- إذا ظهرت أخطاء RPC في Supabase، غالبًا لم تُطبق كل الترحيلات.
